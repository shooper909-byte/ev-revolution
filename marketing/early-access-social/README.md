# Eve's Sisters early access social posts

| File | Size | Use |
| --- | --- | --- |
| `eves-sisters-early-access-feed.png` | 1080×1350 (4:5) | Instagram/Facebook feed post. Put the link in bio or the caption. |
| `eves-sisters-early-access-story.png` | 1080×1920 (9:16) | Stories. Includes the waitlist QR code; add a link sticker to evevolutionhealth.com/early-access. |

Both are built from the early access page artwork (`public/images/early-access/`)
and its QR code, which opens the Brevo waitlist form. Edit `post.html` and run
`node render.cjs` to re-render.
